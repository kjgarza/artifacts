# CLAUDE.md

Shared instructions for agents. `AGENTS.md` is a symlink to this file.

**Kind: content.** Claude-generated HTML artifacts, published to GitHub Pages. Design: `SPEC.md`.

## Rules

- Never edit artifact HTML; the build only moves it. New artifacts go in `inbox/` (use the `publish-artifact` skill).
- `<slug>/`, `index.html` and `manifest.json` are generated by `scripts/build.mjs`; don't hand-edit them. `<slug>/meta.json` (tags, description, kind) may be edited by hand.
- Published slugs are immutable so URLs never break.

## Commands

- `node scripts/build.mjs` - ingest `inbox/`, regenerate `manifest.json` and `index.html`. Idempotent, no dependencies (Node 22).
- `node --test scripts/build.test.mjs` - build tests.
